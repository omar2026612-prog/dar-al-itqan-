# دار الإتقان للمطابخ والديكور — الموقع الإلكتروني

موقع ثابت (Static Site) بتقنيات HTML / CSS / JavaScript بدون أي خطوات بناء (Build) معقدة —
يفتح مباشرة أو يُرفع على أي استضافة فوراً.

---

## 2) طريقة التشغيل محلياً

الموقع لا يحتاج Node.js أو أي تثبيت. فقط:

1. افتح مجلد `itqan` بأي محرر (VS Code مثلاً).
2. استخدم إضافة **Live Server** أو شغّل من الطرفية:
   ```bash
   cd itqan
   python3 -m http.server 8080
   ```
3. افتح المتصفح على `http://localhost:8080`

> ملاحظة: فتح `index.html` مباشرة بنقرتين قد يمنع بعض المتصفحات من تحميل ملفات JS بسبب سياسات الأمان المحلية (CORS) — لذلك يُفضّل خادم محلي بسيط كما بالأعلى.

## 3) تعديل بيانات الشركة (مكان واحد فقط)

افتح `js/config.js` وعدّل:

| الحقل | الوصف |
|---|---|
| `contact.phone` | رقم الهاتف الظاهر في كل الموقع |
| `contact.whatsapp` | رقم واتساب (بصيغة دولية بدون + أو رموز، مثال: `96893966645`) |
| `contact.email` | البريد الإلكتروني |
| `contact.address` | العنوان التفصيلي (عربي/إنجليزي) |
| `contact.workingHours` | ساعات العمل |
| `social.facebook / instagram / tiktok` | روابط التواصل الاجتماعي |
| `googleMapsQuery` | عنوان نصي لموقع المعرض تُبنى منه الخريطة تلقائياً (راجع القسم 6) |
| `whatsappDefaultMessage` | نص الرسالة التلقائية عند الضغط على زر واتساب |

**أي تعديل هنا ينعكس فوراً على كل صفحات الموقع** (الهيدر، الفوتر، زر واتساب، صفحة التواصل...) دون الحاجة لتعديل كل ملف على حدة.

### بيانات لم تُتحقّق بعد (ابحث عن `[...]` في config.js)
- `[COMPANY_EMAIL]`
- `[COMPANY_ADDRESS]` / `[COMPANY_ADDRESS_EN]`
- `[WORKING_HOURS]` / `[WORKING_HOURS_EN]`
- `[GOOGLE_MAPS_ADDRESS]` (عنوان المعرض — يمكن إدخاله مباشرة من لوحة التحكم، راجع القسم 6)

استبدلها ببياناتكم الحقيقية قبل النشر.

## 4) إضافة مشروع جديد إلى معرض الأعمال

1. ضع صور المشروع داخل `images/projects/` (بصيغة `.jpg` أو `.webp` أو `.png`).
2. افتح `js/projects.js` وأضف كائناً جديداً في نهاية المصفوفة `PROJECTS`:

```js
{
  id: "kitchen-new-project",              // معرّف فريد بالإنجليزية بدون مسافات
  category: "kitchens",                    // kitchens | wardrobes | bedrooms | decor
  title: { ar: "اسم المشروع بالعربي", en: "Project name in English" },
  location: { ar: "الموقع إن وجد", en: "Location" },
  cover: "images/projects/my-photo.jpg",
  gallery: ["images/projects/my-photo.jpg", "images/projects/my-photo-2.jpg"],
  description: {
    ar: "وصف المشروع...",
    en: "Project description...",
  },
},
```

سيظهر المشروع تلقائياً في الصفحة الرئيسية ومعرض الأعمال وصفحة التفاصيل الخاصة به
(`project-details.html?id=kitchen-new-project`) دون أي تعديل آخر.

### لإضافة تصنيف فلترة جديد (مثال: "غرف معيشة")
أضف زر فلترة في `portfolio.html`:
```html
<button class="filter-btn" data-filter="living">غرف المعيشة</button>
```
وأضف الترجمة في دالة `categoryLabel` بنفس الملف وفي `index.html`.

## 5) تغيير رقم واتساب

عدّل قيمة `contact.whatsapp` في `js/config.js` فقط — سيتغير زر واتساب العائم،
وزر "واتساب" في كل الصفحات، ونموذج طلب الاستشارة تلقائياً في كل مكان.

---

## 6) إضافة موقع المعرض على خرائط جوجل (أسهل طريقة)

لم تعد بحاجة لأي كود تضمين معقّد:

1. افتح `admin.html` وسجّل الدخول → تبويب **"بيانات الشركة"**.
2. في حقل **"موقع المعرض على خرائط جوجل"** اكتب العنوان نصياً فقط، مثال:
   `معرض دار الإتقان، صحار، عُمان`
3. ستظهر معاينة الخريطة فوراً في نفس الصفحة، وتظهر الخريطة تلقائياً في صفحة **"تواصل معنا"**.
4. (اختياري، لدقة أعلى): بدل كتابة العنوان، يمكنك فتح تطبيق Google Maps، تحديد الموقع بدقة، ثم Share → نسخ الرابط ولصقه في نفس الحقل.
5. (متقدّم واختياري): إن رغبت باستخدام كود "Embed a map" الرسمي من جوجل بدل ذلك، يوجد حقل منفصل تحته لهذا الغرض — لن يُستخدم إلا إذا تركت الحقل الأول فارغاً.

بعد الحفظ، لا تنسَ الضغط على **"⬇ تنزيل ملف الإعدادات (config.js)"** ورفعه ليظهر التعديل لجميع الزوار (راجع قسم "لوحة التحكم" أدناه).

## 7) ربط نموذج التواصل (contact.html)

حالياً: النموذج يجهّز رسالة منسّقة ويفتحها مباشرة على واتساب (لا حاجة لأي خادم خلفي).

**للربط بخدمة بريد إلكتروني** (مثل Formspree أو EmailJS):
- أضف `action` و`method` على وسم `<form id="consultForm">` في `contact.html`، أو
- استخدم مكتبة EmailJS: أضف سكربتها، واستدعِ `emailjs.sendForm(...)` داخل معالج الحدث `submit` في نفس الملف (السكربت المضمّن حالياً بأسفل `contact.html`).

**للربط بخادم خاص (Backend/CRM):**
استبدل الجزء الخاص بإرسال واتساب في `initForm()` داخل `js/main.js` باستدعاء `fetch()` إلى واجهة برمجية (API) خاصة بمكتبكم.

## 8) اللغة الإنجليزية

البنية التحتية للثنائية اللغوية مجهّزة بالكامل عبر `config.js` (كل نص فيه بصيغة `{ ar: "...", en: "..." }`)
وزر `EN/AR` في الهيدر يبدّل بين اللغتين ويحفظ التفضيل في المتصفح.

**ما يحتاج استكمالاً:** النصوص الطويلة داخل ملفات HTML (الأوصاف، الأقسام) مكتوبة حالياً بالعربية فقط داخل كل صفحة.
لإضافة نسخة إنجليزية كاملة: أنشئ نسخة من كل صفحة `.html` بلاحقة `-en` (مثل `index-en.html`)
وترجم المحتوى الثابت فيها، مع إبقاء `js/config.js` كمصدر بيانات مشترك.

## 9) الأداء والصور

- الصور الحالية مأخوذة مباشرة من صور معرض الشركة الفعلي (حجم كبير نسبياً كونها صور هاتف أصلية).
- **يُنصح بشدة** قبل النشر بضغط الصور وتحويلها إلى WebP لتسريع تحميل الموقع، عبر أدوات مثل:
  [Squoosh](https://squoosh.app) أو أي أداة ضغط صور أخرى، مع الحفاظ على نفس أسماء الملفات
  في `images/projects/` و`images/branding/`، أو تحديث المسارات في `js/projects.js` إذا غيّرت الامتداد.

## 10) النشر (Deploy)

هذا الموقع ثابت بالكامل (لا يحتاج Node.js أو قاعدة بيانات)، لذلك يمكن رفعه على أي من:

**Netlify (الأسهل):**
اسحب مجلد `itqan` بالكامل إلى [app.netlify.com/drop](https://app.netlify.com/drop)

**Vercel:**
```bash
npm i -g vercel
cd itqan
vercel --prod
```

**GitHub Pages:**
1. ارفع محتوى المجلد إلى مستودع GitHub.
2. من إعدادات المستودع → Pages → اختر الفرع الرئيسي كمصدر.

**أي استضافة تقليدية (cPanel وغيرها):**
ارفع محتوى مجلد `itqan` بالكامل إلى مجلد `public_html` عبر FTP.

بعد الرفع، لا تنسَ تحديث:
- رابط `<link rel="canonical">` في كل صفحة، ورابط `Sitemap` في `robots.txt`، ورابط `<urlset>` في `sitemap.xml` — استبدل `https://www.daralitqan.om/` بالنطاق الفعلي للموقع.

## 11) لوحة التحكم (admin.html) — إدارة المشاريع والفيديوهات بدون كتابة كود

الموقع فيه الآن لوحة تحكم بسيطة تسمح لصاحب العمل بإضافة/تعديل/حذف المشاريع والفيديوهات
وبيانات الشركة من واجهة مرئية، دون فتح أي ملف كود.

**الدخول:**
1. افتح `admin.html` (مثال: `https://موقعك.com/admin.html`).
2. أدخل كلمة المرور المحددة في `js/config.js` عند الحقل `adminPasscode` (القيمة الافتراضية: `itqan2026` — **غيّرها فوراً** قبل نشر الموقع).
3. بعد أول تسجيل دخول ناجح، يتذكّرك المتصفح — لن يُطلب منك كلمة المرور مرة أخرى على نفس الجهاز إلا إذا ضغطت "تسجيل الخروج".

**⚠️ مهم بخصوص الأمان:** هذه كلمة مرور بسيطة لإبعاد الزوار العاديين فقط، وليست حماية أمنية حقيقية
(الصفحة كود يعمل بالكامل داخل المتصفح). لا تشارك رابط `admin.html` علناً، والصفحة مستثناة من الفهرسة
في `robots.txt` بالفعل. إذا احتجتم حماية أقوى مستقبلاً (تسجيل دخول حقيقي، صلاحيات مستخدمين)، هذا يتطلب
خادم خلفي (Backend) ويمكن إضافته لاحقاً.

**كيف تعمل التعديلات؟**
هذا موقع ثابت (Static) بلا قاعدة بيانات — وهو ما يجعله سريعاً جداً ورخيص الاستضافة. لذلك تعمل لوحة
التحكم كـ"محرِّر محلي":
- أي تعديل تحفظه يظهر لك **فوراً في نفس المتصفح** (معاينة حقيقية على `portfolio.html` و`videos.html`).
- لنشر التعديل لكل الزوار، تضغط زر **"⬇ تنزيل"** في كل تبويب، فيُحمَّل لك ملف الكود المحدَّث
  (`projects.js` أو `videos.js` أو `config.js`) — تستبدل به الملف القديم على الاستضافة (راجع قسم "النشر" أعلاه).
- عند رفع صور مشروع جديد، تُنزَّل الصور تلقائياً بأسماء جاهزة — ضعها داخل `images/projects/` قبل رفع الموقع.

هذا هو نفس أسلوب عمل أنظمة إدارة المحتوى الثابتة (Git-based CMS) المستخدمة في مواقع كثيرة، والفرق
الوحيد أنه يتطلب خطوة "تنزيل ثم رفع" بدل نشر تلقائي فوري.

**تريدون نشراً فورياً بدون رفع ملفات يدوياً؟** ممكن، لكنه يحتاج قاعدة بيانات/خادم خلفي بسيط — أخبرونا
إن رغبتم بذلك لاحقاً وسنجهزه.

## 11.ب) وضع المالك (Owner Mode) — أدوات تحكم على الموقع نفسه، تظهر لك فقط

بالإضافة إلى `admin.html`، الموقع الآن "يتعرّف" على صاحبه في متصفحه بعد أول تسجيل دخول، ويُظهر له
أدوات تحكم مباشرة وهو يتصفح الموقع العام نفسه — بينما يبقى الموقع كما هو تماماً (جاهزاً للعرض فقط،
بدون أي إضافات) لأي زائر آخر لا يحمل متصفحه هذه العلامة.

**ما الذي يظهر لصاحب الموقع فقط (بعد تسجيل الدخول من `admin.html` ولو مرة واحدة):**
- زر دائري عائم (⚙️) في كل صفحات الموقع، يفتح قائمة سريعة: لوحة التحكم الكاملة / إضافة مشروع جديد
  / إضافة فيديو جديد / تسجيل الخروج من "وضع المالك".
- زر ✎ صغير يظهر فوق كل بطاقة مشروع (في الصفحة الرئيسية ومعرض الأعمال) وفوق كل بطاقة فيديو
  (في صفحة الفيديوهات)، ينقله مباشرة لنموذج تعديل ذلك العنصر بعينه في لوحة التحكم.
- بطاقة "+ إضافة مشروع/فيديو جديد" في نهاية كل شبكة عرض.

**كيف تُفعَّل ولمن تظهر؟**
تُفعَّل تلقائياً بمجرد الدخول بكلمة مرور `admin.html` مرة واحدة، وتبقى مفعّلة في **هذا المتصفح على هذا
الجهاز فقط** حتى تضغط "تسجيل الخروج من وضع المالك" من القائمة العائمة. أي شخص آخر يفتح الموقع من
جهازه أو متصفحه الخاص — حتى لو عرف رابط الموقع — لن يرى أياً من هذه الأزرار إطلاقاً، ويظهر له الموقع
بشكل نهائي جاهز للعرض فقط، تماماً كأي زائر عادي.

**ملاحظة:** الضغط على أي من هذه الأزرار يفتح `admin.html` في تبويب جديد على نفس نموذج التعديل مباشرة —
لكن نشر أي تعديل لكل الزوار يتطلب دائماً خطوة "⬇ تنزيل الملف ثم رفعه" الموضحة أعلاه، لأن الموقع ثابت
بلا قاعدة بيانات خلفية.

## 12) الفيديوهات وربط الموقع بصفحة فيسبوك

**صفحة `videos.html`** فيها قسمان:
1. **شبكة فيديوهات** تُدار من `js/videos.js` أو من تبويب "الفيديوهات" في لوحة التحكم — تدعم روابط
   فيديوهات فيسبوك ويوتيوب مباشرة (تُعرض داخل الصفحة عبر التضمين الرسمي من فيسبوك/يوتيوب، بدون أي
   مفتاح API مطلوب).
2. **قسم "تابعنا على فيسبوك"** — تضمين حي (Facebook Page Plugin) لصفحة `itqank` الرسمية. هذا القسم
   **يعمل تلقائياً بالكامل**: أي منشور أو فيديو جديد تنشرونه على فيسبوك يظهر في هذا القسم بمجرد نشره،
   دون أي خطوة يدوية إضافية على الموقع.

لتمييز فيديو معيّن بشكل بارز (بدل تركه يظهر فقط ضمن التغذية العامة)، استخدموا تبويب **"ربط فيسبوك"**
في لوحة التحكم: الصقوا رابط منشور الفيديو، عاينوه، ثم اضغطوا "إضافة كفيديو دعائي" ليُضاف إلى شبكة
الفيديوهات المميزة.

## ملاحظة أخيرة بخصوص المصداقية

تم بناء هذا الموقع دون الوصول إلى صفحة فيسبوك الرسمية للشركة (يمنع فيسبوك الأدوات الآلية من قراءتها).
البيانات الحقيقية المستخدمة (الاسم الرسمي، رقم الهاتف 93966645، قائمة الخدمات، وصور الأعمال) مأخوذة من
صور واجهة المعرض والمعرض الداخلي التي زوّدتنا بها مباشرة. أي بيانات أخرى (البريد الإلكتروني، العنوان التفصيلي،
ساعات العمل، رابط الخريطة) ما زالت قيد الانتظار وموضوعة كمتغيرات واضحة `[...]` في `js/config.js`.
